# Project scope

## Research objective

QuantumPINN will evaluate a physics-informed neural network on a controlled family of
one-dimensional stationary quantum problems, then extend the same physics constraint
to an inverse problem. The headline question is:

> Can a PINN recover accurate eigenpairs for simple 1D systems, and under what data
> assumptions can it reconstruct an unknown potential?

This is an evaluation project rather than a demonstration-only notebook. Every PINN
result must be compared with either an analytical solution or an independent numerical
reference.

## In scope

### 1. Reference solvers and benchmarks

- Uniform-grid, second-order finite-difference Hamiltonian with Dirichlet boundaries.
- Analytical references for the infinite square well and harmonic oscillator.
- Low-lying eigenpairs for:
  - infinite square well;
  - harmonic oscillator;
  - symmetric double well, where tunnelling is represented by the splitting of the
    lowest symmetric and antisymmetric states.
- Reproducible metrics: relative energy error, sign-invariant wavefunction `L2` error,
  boundary residual, normalisation residual, PDE residual, runtime, and convergence
  with grid/collocation resolution.

### 2. Forward PINN

- A multilayer perceptron representing one wavefunction and a trainable scalar energy.
- Automatic differentiation for the second spatial derivative.
- A trial-function transform for exact Dirichlet boundary conditions where practical.
- Loss terms for the Schrödinger residual and normalisation.
- Excited states trained using parity and/or orthogonality to already learned states;
  residual minimisation alone is not sufficient to select a requested eigenstate.
- Deterministic experiment configuration, recorded random seeds, checkpoints, and
  machine-readable metrics.

### 3. Inverse potential reconstruction

- Synthetic observations generated by the independent reference solver.
- Begin with a low-dimensional potential family (for example `a*x**2 + b*x**4`) before
  attempting a free-form neural potential.
- Use one or more observed energies and signed wavefunctions or densities. A density-only
  ground-state experiment is allowed; excited-state densities require special handling
  near nodes.
- Resolve the additive-energy ambiguity by fixing the potential at a reference point or
  by supplying an absolute energy level.
- Regularise free-form potentials for smoothness and report sensitivity to observation
  location and count.
- Evaluate both noiseless data and a small, explicitly specified noise sweep.

## Out of scope for the initial release

- Time-dependent, two-dimensional, relativistic, many-body, or quantum-chemistry models.
- Barrier transmission coefficients and open-boundary scattering. These require a
  scattering formulation rather than the bound-state eigenproblem used here.
- Production UI, distributed/GPU-heavy training, transformers, or architecture search.
- Claims of superiority based only on training loss or a single successful seed.
- Experimental laboratory data; the first release uses synthetic observations so that
  ground truth and identifiability are controlled.

## Scientific risks and controls

| Risk | Control |
|---|---|
| PINN collapses to `psi = 0` | Explicit normalisation and a non-zero trial state |
| Training returns only the ground state | Parity/orthogonality constraints and state-specific evaluation |
| Eigenfunction has arbitrary sign | Sign-aligned error metric |
| Inverse potential is non-identifiable up to a constant | Fix a gauge or provide absolute energy |
| Density loses wavefunction sign | Start with a nodeless ground state; state assumptions explicitly |
| Finite-domain truncation biases oscillator results | Domain-size convergence study |
| A single run hides optimiser instability | Multiple seeds with mean and spread |
| PINN and reference share the same bug | Analytical cases plus an independent finite-difference implementation |

## Deliverables and acceptance criteria

### Milestone 1: numerical baseline (implemented)

- Reusable potentials and finite-difference eigensolver.
- Analytical square-well and oscillator references.
- Automated tests showing the first three energies converge to known values.
- A CLI-style benchmark that prints energy and wavefunction errors.

### Milestone 2: forward PINN

- Ground states for the square well and oscillator.
- At least the first two excited states using explicit state-selection constraints.
- Plots and a table comparing analytical, finite-difference, and PINN results.
- A documented resolution/seed study. Target errors will be set from an initial sweep;
  they will not be chosen after seeing only the best run.

### Milestone 3: tunnelling benchmark

- Lowest double-well eigenstates and their energy splitting.
- PINN comparison against the converged finite-difference reference.
- A parameter sweep showing how splitting changes with barrier strength or well spacing.

### Milestone 4: inverse problem

- Recover harmonic/quartic coefficients from sparse synthetic observations.
- Compare reconstructed and true potentials on held-out grid points.
- Report parameter error, potential `L2` error, and forward consistency of reconstructed
  eigenpairs.
- Repeat across several noise levels and seeds.

### Milestone 5: final report

- Four or five publication-quality figures, a compact results table, reproducible
  commands, dependency lock information, and a limitations section.

## Recommended experiment matrix

| Problem | States | Reference | Primary purpose |
|---|---:|---|---|
| Infinite well | 0–2 | analytical + finite difference | boundaries and excited-state selection |
| Harmonic oscillator | 0–2 | analytical + finite difference | smooth unbounded potential and domain truncation |
| Symmetric double well | 0–1 | converged finite difference | tunnelling-induced energy splitting |
| Hidden quadratic/quartic potential | ground, then 0–2 | synthetic finite difference | inverse identifiability and noise robustness |

## Definition of done

The project is complete when a clean environment can reproduce the reference tests,
train the selected PINN experiments from configuration, regenerate every reported
metric and figure, and expose both successful cases and observed failure modes. The
final conclusion should distinguish the efficiency of conventional forward solvers
from the flexibility of PINNs for incomplete-data inverse problems.
